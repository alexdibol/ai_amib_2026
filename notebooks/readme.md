# Colab notebooks — What a CEO Needs to Learn About AI

All six practical notebooks are available. They support the three-lesson, six-part programme by making specific mechanisms observable through synthetic financial cases. Each contains ten code cells with explanatory material. Read the narrative and inspect the results to connect the experiment to a management decision; the examples complement the monographs rather than reproducing every topic.

## How to use the notebooks

1. Choose **Open in Colab** below and start a fresh standard CPU runtime.
2. For live model responses, add `ANTHROPIC_API_KEY` in Colab **Secrets** and enable notebook access. Live API use requires access to the configured Anthropic model and can incur charges.
3. Alternatively, set `LIVE_LLM = False` in the configuration cell to use explicitly labelled offline teaching fixtures. These fixtures are not live model responses.
4. Run the cells in order. Compare the evidence, decisions and control outcomes, then use the discussion to identify what would justify changing the system's authority.

The exercises use synthetic data and simulated institutional actions. Live mode sends prompts to Anthropic. Each notebook's configuration identifies its selected model: Lecture 1 Part 1 uses `claude-sonnet-4-5-20250929`; the other five use `claude-haiku-4-5-20251001`.
