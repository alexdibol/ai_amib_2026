# Speech — What a CEO Needs to Learn About AI

The Spanish-language speech is the executive entry point to the programme. It traces the move from analytical models to agentic and adaptive organisations, explaining the responsibilities that accumulate as capability and delegated authority expand. It closes with four leadership decisions: protect, create a space to innovate, budget, and educate.
